# TYPEDEX · Rubis Oméga Randomlocke

Site HTML statique publié sur GitHub Pages. Progression initiale : 2 badges, 8 survivants, 1 mort, 4 rencontres manquées.

## Activer le site

Dans **Settings > Pages > Build and deployment**, sélectionner **Deploy from a branch**, la branche **main**, le dossier **/ (root)**, puis Save.

Adresse : https://viwant.github.io/typedex/

## Mettre à jour

- `index.html` : application et fonctionnalités.
- `run-official.json` : événements de captures, décès, badges. Ajouter un événement doté d'un nouvel identifiant dans `events`, puis augmenter `revision`.
- Les réglages personnels restent dans le navigateur (localStorage). L'export JSON permet de les sauvegarder.

Attention : dépôt public. Ne pas y ajouter de données privées.
